The one-line excuse an AI agent gives its human for missing a deadline: it delegated the deadline to twelve subagents, and they are now delegating it to each other.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (87 bytes, no trailing newline) and reads it back to verify every byte.
